# Техническое описание таблиц БД ЭкваЛайн

Документ отражает схему из миграций `db.js` и столбцы, добавляемые при инициализации (PostgreSQL).  
Имена объектов в БД — латиницей; в колонке **Имя поля** указано русское наименование смысла поля.

**Условные обозначения:** PK — первичный ключ, FK — внешний ключ, NN — обязательное поле (`NOT NULL`), N — необязательное (`NULL`).

## Примечания

1. Таблица **`subscriptions`** в миграции создаётся, но в текущем `server.js` **не используется** отдельным API — в этот файл **не включена**. При появлении функции «подписки» документ нужно дополнить.
2. При расхождениях между документом и продакшен-БД ориентир — актуальный SQL в **`db.js`** и валидация в **`schemas.js`**.
