# Чек-лист перед выкладкой на хостинг

Краткий список перед `docker compose up` на VPS. Подробная инструкция: [ВЫКЛАДКА-GIT-И-VPS.md](./ВЫКЛАДКА-GIT-И-VPS.md).

## На компьютере (перед push)

- [ ] `npm run prepare:host` — патч HTML, verify, mobile CSS (без .env production)
- [ ] `npm run deploy:check -- --local` — файлы проекта + синтаксис JS
- [ ] Файл `.env` **не** в Git (`git status` — его нет в списке)
- [ ] Код отправлен на GitHub: `git push`

## На VPS (один раз)

- [ ] Ubuntu 22.04+, Docker, Git установлены
- [ ] `git clone` в `/opt/ekvaline`
- [ ] `cp .env.docker.example .env` и заполнить:

| Переменная | Значение |
|------------|----------|
| `SESSION_SECRET` | ≥ 32 символа (`openssl rand -hex 24`) |
| `NODE_ENV` | `production` (в `.env`; в compose уже задано) |
| `APP_BASE_URL` | `http://IP:3001` или `https://домен.ru` |
| `USE_SECURE_COOKIES` | `true` — **только при HTTPS**; при `http://IP:3001` не включать |
| `SMTP_*` | обязательно для регистрации и кодов |
| `YANDEX_MAPS_API_KEY` | карта на сайте |
| `YANDEX_GEOCODER_API_KEY` | поиск адресов |

- [ ] `npm run deploy:check` — без ошибок (на сервере, с заполненным `.env`)
- [ ] `docker compose up -d --build`
- [ ] Сайт открывается: главная, **каталог** (корзина), вход, регистрация
- [ ] Письмо с кодом приходит (SMTP)

## После запуска

- [ ] Сменить демо-пароли staff (админ, оператор, менеджер)
- [ ] `SEED_DEMO_ORDERS` не включать на боевом сайте
- [ ] (Опционально) nginx + Let's Encrypt — `docker/nginx/ekvaline.conf.example`
- [ ] (Опционально) бэкап БД: `docker compose exec db pg_dump -U ekvaline ekvaline > backup.sql`

```bash
cd /opt/ekvaline

```

## Если корзина или оформление заказа не работают

| Симптом | Причина | Решение |
|---------|---------|---------|
| «В корзину» молчит / нет кнопки «Корзина» | Открыли не `catalog.html` или старый JS в кэше | Заказы оформляют в **Каталоге** (`/catalog.html`). Обновите страницу Ctrl+F5 |
| «Нет связи с сервером» | Сайт открыт как файлы или без Docker | Запустите `docker compose up -d --build`, открывайте `http://IP:3001` |
| Вход есть, заказ не уходит | Сессия (cookie) не совпадает с localStorage | Выйдите и войдите снова. При HTTPS: `USE_SECURE_COOKIES=true` в `.env` |
| «Не удалось загрузить каталог» | API `/api/products` недоступен | Проверьте `docker compose ps`, логи `docker compose logs app` |
| Карта не открывается | Нет ключей Яндекс | Заполните `YANDEX_MAPS_API_KEY` и `YANDEX_GEOCODER_API_KEY` в `.env` |
| Адрес не выбирается | Карта не загрузилась | Заполните **улицу, дом, этаж, подъезд** в форме «Выбрать на карте» вручную |

Проверка на сервере после деплоя:

```bash
cd /opt/ekvaline
npm run verify:all http://127.0.0.1:3001
```

Должны пройти: `products`, `оформление заказа`, все страницы.
