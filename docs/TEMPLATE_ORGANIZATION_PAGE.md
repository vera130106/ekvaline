# Шаблон страницы «О компании» (карточка организации на сайте ЭкваЛайн)

Шаблон страницы с информацией об организации представлен следующим видом (логическая структура блоков повторяет классическую схему: верхняя витрина компании, блок поэтапной информации, блок подтверждающих документов, общая обвязка сайта — шапка и подвал).

**Важно:** в текущей статической реализации элементы заданы в разметке постоянно. При переносе на динамические данные (БД) отдельные фрагменты — например, описание этапа, конкретный сертификат, дополнительный реквизит — могут **не выводиться**, если соответствующее поле не заполнено (аналог условий `if` в серверном шаблоне).

---

## Связь с универсальным шаблоном «организация» (реквизиты + иконки)

В учебном примере с PHP блоки **`info_about`** (ИНН, ОГРН), **`main-info-organization`** и **`block-with-image`** отражают ту же логику: **сводка по полям** и **ключ–значение с пиктограммой**. На сайте ЭкваЛайн аналогичную роль несёт:

| Логика в примере с ОКВЭД/ИНН | На сайте ЭкваЛайн |
|-----------------------------|-------------------|
| Верхняя центрированная строка кода вида деятельности | `about-kicker` + заголовок `h1` в `about-hero-copy` |
| Блок реквизитов (`info_about`) | По желанию — отдельный `<div>` внутри `container` перед `about-pillars` (пока не вынесен в отдельный блок в репозитории) |
| Разделитель | Можно оформить отдельным `<hr>` или полосой через класс из `styles.css` |
| Ряд блоков «иконка + текст» (`block-with-image`) | Смысловой аналог — карточки этапов и карточки сертификатов (`about-step-panel`, `about-cert-card`) |

Если понадобится **точная** универсальная вёрстка в духе `block-with-image`, её можно добавить одной секцией с теми же данными организации без смены остальной страницы.
