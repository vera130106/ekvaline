# Настройка реальной почты (ЭкваЛайн)

Пока в `.env` пустой `SMTP_PASS`, коды **не уходят на email** — они печатаются в консоли при `node server.js`.

## Шаг 1. Пароль приложения Mail.ru

1. Откройте [mail.ru](https://mail.ru) → войдите в ящик `verunya_ivanova_0606@mail.ru` (или ваш рабочий).
2. **Настройки** → **Пароль и безопасность** → **Пароли для внешних приложений**.
3. Создайте пароль для «Почтовая программа» / SMTP.
4. Скопируйте выданный пароль (один раз показывается).

Справка: https://help.mail.ru/mail/mailer/password

## Шаг 2. Файл `.env` в корне проекта

Уже добавлено (проверьте строку `SMTP_PASS`):

```env
SMTP_HOST=smtp.mail.ru
SMTP_PORT=465
SMTP_SECURE=1
SMTP_USER=verunya_ivanova_0606@mail.ru
SMTP_PASS=вставьте_сюда_пароль_приложения
SMTP_FROM=ЭкваЛайн <verunya_ivanova_0606@mail.ru>
APP_BASE_URL=http://localhost:3001
```

**Важно:** в `SMTP_PASS` — только пароль приложения, без кавычек и пробелов в начале/конце.

## Шаг 3. Проверка без сайта

```bash
npm run test:smtp
```

Должно быть: «Подключение OK» и «Проверьте входящие».

## Шаг 4. Перезапуск сервера

Остановите `node server.js` (Ctrl+C) и снова:

```bash
npm start
```

В консоли должно появиться:

`Почта (SMTP): подключение проверено, письма уходят на реальные ящики.`

После этого в консоли **не должно** быть блоков `[mail] SMTP не настроен` с кодом.

## Шаг 5. Проверка на сайте

- Регистрация нового клиента → письмо с кодом.
- Кабинет → «Подтверждение email» → «Отправить код на email».
- «Смена пароля» или `reset-password.html`.

Проверьте папку **Спам**.

## Яндекс / Gmail

| Сервис | SMTP_HOST | PORT | SMTP_SECURE |
|--------|-----------|------|-------------|
| Яндекс | smtp.yandex.ru | 465 | 1 |
| Gmail | smtp.gmail.com | 587 | 0 |

Для Gmail нужен пароль приложения Google Account.

## Ошибки

| Симптом | Решение |
|---------|---------|
| Код в консоли сервера | `SMTP_PASS` пустой или сервер не перезапущен |
| `Invalid login` | Неверный пароль приложения, не пароль от входа в mail.ru |
| Письма в спаме | Нормально на localhost; на продакшене укажите домен в `APP_BASE_URL` |
| `connection timeout` | Антивирус/фаервол блокирует порт 465 |

Я не могу подставить ваш `SMTP_PASS` за вас — его знаете только вы из кабинета Mail.ru.
